# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/ZXY101/yt-stream-sync/security/advisories/new).

Include what's affected, how to reproduce it and what an attacker could do. You'll get an
answer within a week. Once a fix is released, the advisory is published with credit to you,
unless you'd rather stay anonymous.

## Scope

In scope: the add-on itself, e.g. a web page making the add-on act on its behalf (messages
from the page world are treated as untrusted), access beyond the permissions it declares,
or leaking browsing data.

Out of scope: bugs in YouTube, Holodex or the browsers themselves.
